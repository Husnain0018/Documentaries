System Documentation: Botify AI Website

Version: 1.0 | Developer: Ali Husnain | Date: October 2023 | Stack: HTML5, CSS3, Vanilla JS

1. Introduction

1.1 Project Overview

Botify AI is a multi-page, responsive static website designed to showcase and provide a simulated experience of AI Chatbot services for businesses. The project focuses on clean UI/UX design, frontend interactivity, and modern web standards without relying on external frameworks or backend servers.

1.2 Purpose

The primary purpose of this system is to act as a digital portfolio and business landing page for AI chatbot solutions. It demonstrates frontend development capabilities, including DOM manipulation, event handling, and responsive design.

1.3 Scope

  • In Scope: 6 fully linked HTML pages, responsive CSS layout, interactive chatbot simulation, frontend form validation, UI animations.
  • Out of Scope: Backend database integration, real Natural Language Processing (NLP) API connections, user authentication, actual email sending.

2. System Architecture

The project follows a standard Separation of Concerns (SoC) architecture typical of modern frontend development.

  • Presentation Layer (HTML): Semantic markup structuring the UI into reusable components (Navbar, Footer, Cards).
  • Styling Layer (CSS): CSS Custom Properties (Variables) for theming, Flexbox/Grid for layout algorithms.
  • Logic Layer (JavaScript): Modular Vanilla JS handling DOM events, state changes, and algorithmic logic (chatbot responses).

3. Component Design (Class Diagram)

Since this is a Vanilla JavaScript application without traditional Object-Oriented backend classes, the system is modeled conceptually based on Controller Modules and DOM Entities. The UIManager handles generic view updates, while the ChatbotEngine and FormHandler encapsulate specific business logic.

classDiagram class UIManager { -HTMLElement hamburger -HTMLElement navLinks +initMobileMenu() void +toggleMenu() void +closeMenu() void } class ChatbotEngine { -HTMLElement chatInput -HTMLElement sendBtn -HTMLElement chatMessages +handleSendEvent() void -appendMessage(sender: String, text: String) void -evaluateInput(text: String) String } class FormHandler { -HTMLElement contactForm +handleSubmission(event: Event) void -validateFields() boolean -resetForm() void } class MessageEntity { +String sender +String content +display() void } UIManager --> ChatbotEngine : triggers init UIManager --> FormHandler : triggers init ChatbotEngine --> MessageEntity : creates

Class Descriptions:

  • UIManager: Controls global UI states. Listens for clicks on the hamburger element to toggle the mobile menu.
  • ChatbotEngine: Manages the state of the demo chat. Listens to 'click' and 'keypress' events. Instantiates MessageEntity concepts by appending divs to the DOM based on string-matching logic.
  • FormHandler: Intercepts the default HTML form submission, checks for empty strings, triggers browser alerts, and resets the DOM state if successful.

6. UI/UX Design System

The visual consistency is maintained through CSS Custom Properties defined in the :root selector.

  • Color Palette: Primary (#0f172a), Secondary (#2563eb), Accent (#06b6d4).
  • Typography: System font stack for fast loading. Line height set to 1.6 for accessibility.
  • Responsive Breakpoint: Single breakpoint at 768px to collapse navigation and stack grids.

7. Testing & Quality Assurance

  1. Cross-Browser: Tested on Chrome, Firefox, Safari, and Edge.
  2. Responsive: Simulated viewports (Mobile 375px, Tablet 768px, Desktop 1440px).
  3. Functional: Verified empty input handling, case insensitivity in chatbot, and form clearing mechanisms.
  4. Link Integrity: Audited all anchor tags to confirm zero 404 errors locally.

8. Limitations & Future Enhancements

Current Limitations: No persistent storage (chat history lost on refresh). No backend (contact form simulates action). Rigid chatbot logic (relies on basic string matching).

Future Enhancements: Integrate localStorage. Connect form to EmailJS or Node.js backend. Replace if/else chatbot with OpenAI API.
